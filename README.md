## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- AOS (Animate On Scroll)
- Font Awesome
- Lottie
- CDN-hosted animation libraries (Vanta.js, tsParticles, Spline runtime)

## Key Features

- Responsive single-page layout
- Light/Dark theme toggle (saved in `localStorage`)
- Smooth scrolling and active nav highlighting
- Mobile navigation menu
- Scroll-based animations
- Interactive project case study modal
- Contact form (`mailto:` based)
- Back-to-top button
- Downloadable resume button

## Run Locally

No build setup is required.

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd myPortfolio
   ```
2. Open `index.html` directly in a browser, or use a local server.

Example local server (VS Code Live Server or Python):

```bash
python -m http.server 5500
```

Then open: `http://localhost:5500`

## Customize Content

- Update personal details and sections in `index.html`
- Update styles in `css/style.css`
- Update interactions/animations in `js/main.js`
- Replace profile image in `images/profile.jpg`
- Replace resume in `resume/SAHILKUMAR_PRASAD_SDE_RESUME.pdf`
